# 중학수학 숲지도

> 나무를 보느라 숲을 보지 못한다! 목차도 외우지 못하면 수학을 포기하는 것과 같다.

중학수학 전체 목차를 **초등 → 중1 → 중2 → 중3** 흐름으로 한눈에 보고,
각 항목을 누르면 초등 5학년 눈높이의 개념설명·예시·확인 문제를 볼 수 있는 선행학습 사이트입니다.

## 폴더 구조

```
index.html        목차 지도 (첫 화면)
assets/           style.css, app.js (공통)
elem/index.html   초등 수학 다시 보기
m1/               중1 단원 (11개)
m2/               중2 단원 (8개)
m3/               중3 단원 (8개)
```

## GitHub Pages로 공개하기

1. 이 폴더의 내용을 저장소(예: `middle-math`) 최상위에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment**에서
   Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 저장합니다.
3. 잠시 후 `https://<사용자이름>.github.io/middle-math/` 에서 열립니다.

## 기능

- **목차 가리고 외우기**: 항목을 가린 뒤 하나씩 눌러 확인
- **✓ 이해 표시**: 단원별 이해 여부를 브라우저에 저장 (기기마다 따로 저장됨)
- 단원마다 한 줄 요약, 왜 배울까, 꼭 외울 것, 확인 문제 3개, 앞뒤 연결 단원
- 라이트/다크 모드 자동 대응, 휴대폰 화면 대응
