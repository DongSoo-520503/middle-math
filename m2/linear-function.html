일차함수와 그래프

y = ax + b, 연립방정식과 그래프

한 줄로 외우기

y = ax + b 의 그래프는 직선이다. a는 기울기(얼마나 가파른지), b는 y절편(y축과 만나는 곳)이다.

왜 배울까?택시 요금(기본요금 + 거리마다 추가 요금), 물통에 물 채우기처럼 일정하게 늘거나 주는 현상은 모두 일차함수다. 식과 직선 그래프를 오가며 생각하는 힘을 기른다.

  • 함수란?
  • 일차함수 y = ax + b
  • 일차함수와 연립방정식

1함수란?

x의 값 하나를 정하면 y의 값이 하나로 정해질 때, y를 x의 함수라 한다. 자판기에 버튼(x)을 누르면 음료(y)가 하나 나오는 것과 같다.

예
한 개 700원인 빵 x개의 값 y → y = 700x (x가 정해지면 y가 하나로 정해짐 → 함수)

2일차함수 y = ax + b

y가 x에 대한 일차식으로 나타날 때 일차함수라 한다 (a ≠ 0).

  • 기울기 a = y의 값의 증가량x의 값의 증가량 : x가 1 늘 때 y가 얼마나 느는지
  • y절편 b: 그래프가 y축과 만나는 점의 y좌표 (x = 0일 때 y)
  • x절편: 그래프가 x축과 만나는 점의 x좌표 (y = 0으로 놓고 구함)
  • y = ax + b의 그래프는 y = ax의 그래프를 y축 방향으로 b만큼 평행이동한 직선
  • a > 0이면 오른쪽 위로, a < 0이면 오른쪽 아래로 향한다. |a|가 클수록 가파르다.
  • 기울기가 같고 y절편이 다르면 두 직선은 평행
식 구하기
두 점 (1, 3), (3, 7)을 지나는 직선 → 기울기 = (7 − 3) ÷ (3 − 1) = 2 → y = 2x + b에 (1, 3)을 넣으면 b = 1 → y = 2x + 1

3일차함수와 연립방정식

x + y = 4 처럼 미지수가 2개인 일차방정식의 해를 좌표평면에 모두 찍으면 직선이 된다 (y = −x + 4).

그래서 연립방정식의 해 = 두 직선의 교점이다.

x + y = 4x − y = 2
  • 두 직선이 한 점에서 만나면 → 해가 하나
  • 두 직선이 평행하면 → 해가 없다
  • 두 직선이 겹치면 → 해가 무수히 많다

꼭 외울 것

  • y = ax + b: a는 기울기, b는 y절편
  • 기울기 = y 증가량 ÷ x 증가량
  • 기울기가 같으면 평행
  • 연립방정식의 해 = 두 직선의 교점

확인 문제

1y = −3x + 6의 기울기, y절편, x절편은?답 보기
기울기 −3, y절편 6, 0 = −3x + 6 → x절편 2
2기울기가 2이고 점 (0, −1)을 지나는 직선의 식은?답 보기
y절편이 −1이므로 y = 2x − 1
3y = x + 1 과 y = −x + 3 의 교점은?답 보기
x + 1 = −x + 3 → x = 1, y = 2 → (1, 2)
