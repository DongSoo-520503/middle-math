곱셈공식과 인수분해

한 줄로 외우기

곱셈공식은 괄호를 펼치는 것, 인수분해는 그 반대로 식을 곱의 꼴로 묶는 것이다. 이차방정식을 풀 때 핵심 도구가 된다.

왜 배울까?(a + b)2을 매번 하나하나 곱하지 않고 공식으로 바로 펼친다. 거꾸로 x2 + 5x + 6을 (x + 2)(x + 3)으로 묶을 수 있으면 이차방정식이 쉽게 풀린다.

  • 곱셈공식
  • 인수분해

1곱셈공식

기본은 분배법칙: (a + b)(c + d) = ac + ad + bc + bd

(a + b)2 = a2 + 2ab + b2
(a − b)2 = a2 − 2ab + b2
(a + b)(a − b) = a2 − b2
(x + a)(x + b) = x2 + (a + b)x + ab
(ax + b)(cx + d) = acx2 + (ad + bc)x + bd
암산
1022 = (100 + 2)2 = 10000 + 400 + 4 = 10404
99 × 101 = (100 − 1)(100 + 1) = 10000 − 1 = 9999

2인수분해

하나의 다항식을 두 개 이상의 식의 곱으로 나타내는 것을 인수분해라 한다. 곱셈공식을 거꾸로 쓰면 된다.

방법예
공통인수 묶기2x2 + 4x = 2x(x + 2)
완전제곱식x2 + 6x + 9 = (x + 3)2
합차 공식x2 − 9 = (x + 3)(x − 3)
곱이 상수항, 합이 x의 계수인 두 수 찾기x2 + 5x + 6 → 곱 6, 합 5 → 2와 3 → (x + 2)(x + 3)
예
x2 − x − 12 → 곱이 −12, 합이 −1인 두 수: −4와 3 → (x − 4)(x + 3)

꼭 외울 것

  • (a ± b)² = a² ± 2ab + b²
  • (a + b)(a − b) = a² − b²
  • 인수분해 = 곱셈공식 거꾸로
  • x² + px + q: 곱 q, 합 p인 두 수 찾기
