이차방정식

한 줄로 외우기

ax² + bx + c = 0 꼴의 방정식. 인수분해해서 'A × B = 0이면 A = 0 또는 B = 0'을 쓰거나, 근의 공식으로 푼다.

왜 배울까?넓이, 떨어지는 물체, 이익 계산처럼 'x × x'가 들어가는 문제는 일차방정식으로 풀 수 없다. 중1 일차방정식의 다음 단계이고, 인수분해와 제곱근을 모두 써먹는 단원이다.

  • 이차방정식이란
  • 인수분해로 풀기
  • 제곱근으로 풀기
  • 근의 공식
  • 활용

1이차방정식이란

모든 항을 왼쪽으로 옮겨 정리했을 때 ax2 + bx + c = 0 (a ≠ 0) 꼴이 되는 방정식이다. 해(근)는 많아야 2개다.

2인수분해로 풀기

두 수를 곱해서 0이면, 둘 중 적어도 하나는 0이다: AB = 0 이면 A = 0 또는 B = 0

x2 − 5x + 6 = 0
(x − 2)(x − 3) = 0
x = 2 또는 x = 3
예
x2 − 6x + 9 = 0 → (x − 3)2 = 0 → x = 3. 두 근이 겹쳐서 하나인 경우를 중근이라 한다.

3제곱근으로 풀기

x2 = k 꼴이면 x = ±√k

예
x2 = 9 → x = ±3
(x − 1)2 = 5 → x − 1 = ±√5 → x = 1 ± √5

4근의 공식

인수분해가 잘 안 될 때는 어떤 이차방정식이든 풀 수 있는 공식을 쓴다.

x = −b ± √b2 − 4ac2a

예
x2 + 3x + 1 = 0 (a = 1, b = 3, c = 1) → x = −3 ± √9 − 42 = −3 ± √52

근호 안의 b2 − 4ac를 보면 근의 개수를 알 수 있다: 양수면 2개, 0이면 1개(중근), 음수면 없음.

5활용

예
연속하는 두 자연수의 곱이 56이다 → x(x + 1) = 56 → x2 + x − 56 = 0 → (x + 8)(x − 7) = 0 → x = 7 (자연수이므로 −8은 버린다) → 7과 8
주의
활용 문제에서는 구한 해가 문제의 조건(자연수, 길이는 양수 등)에 맞는지 꼭 확인한다.

꼭 외울 것

  • AB = 0 이면 A = 0 또는 B = 0
  • x² = k → x = ±√k
  • 근의 공식 x = (−b ± √(b² − 4ac)) / 2a
  • 답이 조건에 맞는지 확인

확인 문제

1x2 − 4x = 0답 보기
x(x − 4) = 0 → x = 0 또는 x = 4
2x2 + 2x − 15 = 0답 보기
(x + 5)(x − 3) = 0 → x = −5 또는 x = 3
32x2 − x − 3 = 0 을 근의 공식으로답 보기
x = 1 ± √1 + 244 = 1 ± 54 → x = 32 또는 x = −1
