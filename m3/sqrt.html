제곱근과 실수

제곱근, 무리수와 실수

한 줄로 외우기

제곱해서 a가 되는 수가 a의 제곱근(±√a)이다. √2처럼 분수로 나타낼 수 없는 수가 무리수이고, 유리수와 무리수를 합쳐 실수라 한다.

왜 배울까?넓이가 2인 정사각형의 한 변은 얼마일까? 1.4도 아니고 1.5도 아니다. 이런 길이를 나타내려면 새로운 수 √2가 필요하다. 초등 자연수 → 중1 정수·유리수 → 중3 실수로, 수의 세계가 완성된다.

  • 제곱근

1제곱근

어떤 수 x를 제곱해서 a가 될 때(x2 = a), x를 a의 제곱근이라 한다.

예
32 = 9, (−3)2 = 9 → 9의 제곱근은 3과 −3 (±3)
  • 양수 a의 제곱근은 두 개: 양수인 √a와 음수인 −√a (기호 √는 '루트'라고 읽는다)
  • 0의 제곱근은 0 하나
  • 음수의 제곱근은 (실수에서는) 없다. 제곱하면 항상 0 이상이기 때문

(√a)2 = a     √a2 = |a|

크기 비교: 0 < a < b 이면 √a < √b. 예: √4 < √5 < √9 이므로 2 < √5 < 3

2무리수와 실수

√2 = 1.41421356… 처럼 소수점 아래가 순환하지 않고 끝없이 계속되는 소수를 무리수라 한다. 분수로 나타낼 수 없다. 원주율 π도 무리수다.

실수
유리수 (분수로 쓸 수 있는 수)
정수
자연수 1, 2, 3 …
0, −1, −2 …
12, 0.3 …
무리수√2, π, 1.0100100010…

한 변이 1인 정사각형의 대각선 길이는 피타고라스 정리로 √1 + 1 = √2다. 컴퍼스로 이 길이를 수직선에 옮기면 √2의 위치를 정확히 찍을 수 있다. 유리수와 무리수, 즉 실수로 수직선이 빈틈없이 채워진다.

3근호가 있는 식의 계산

규칙예
√a × √b = √ab√2 × √8 = √16 = 4
√a ÷ √b = √a/b√12 ÷ √3 = √4 = 2
근호 밖으로 꺼내기√12 = √4 × 3 = 2√3
분모의 유리화1√2 = √22 (분모·분자에 √2를 곱함)
덧셈·뺄셈 (같은 근호끼리)2√3 + 5√3 = 7√3
주의
√2 + √3 ≠ √5. 근호 안이 다르면 더할 수 없다 (x + y를 하나로 못 합치는 것과 같다).

꼭 외울 것

  • a의 제곱근 = ±√a
  • √(a²) = |a|
  • 무리수 = 순환하지 않는 무한소수
  • 실수 = 유리수 + 무리수
  • √a × √b = √ab, 덧셈은 같은 근호끼리만
