산포도

편차, 분산, 표준편차

한 줄로 외우기

평균이 같아도 자료가 얼마나 흩어져 있는지는 다를 수 있다. 흩어진 정도를 나타내는 값이 분산과 표준편차다.

왜 배울까?두 학생의 평균 점수가 둘 다 8점이어도, 한 명은 매번 8점 근처이고 다른 한 명은 4점과 12점을 오간다. 대푯값만으로는 이 차이를 알 수 없어서 '흩어진 정도'를 따로 잰다.

  • 편차
  • 분산과 표준편차

1편차

편차 = 변량 − 평균

평균보다 크면 편차가 양수, 작으면 음수다. 편차를 모두 더하면 항상 0이다 (평균보다 큰 쪽과 작은 쪽이 딱 맞게 상쇄된다).

2분산과 표준편차

편차의 합은 항상 0이라서 흩어진 정도를 알 수 없다. 그래서 편차를 제곱해서 음수를 없앤 뒤 평균을 낸다.

분산 = (편차)2의 총합변량의 개수     표준편차 = √분산

예: 두 학생의 다섯 번 쪽지시험 점수

점수평균분산표준편차
A468101288√8 ≈ 2.83
편차−4−2024합 = 0
B7888980.4√0.4 ≈ 0.63
편차−10001합 = 0

A의 분산 = (16 + 4 + 0 + 4 + 16) ÷ 5 = 8, B의 분산 = (1 + 0 + 0 + 0 + 1) ÷ 5 = 0.4

평균은 같지만 B의 표준편차가 훨씬 작다 → B의 점수가 더 고르다. 표준편차가 작을수록 자료가 평균 가까이 모여 있다.

꼭 외울 것

  • 편차 = 변량 − 평균
  • 편차의 합 = 0
  • 분산 = 편차²의 평균
  • 표준편차 = √분산, 작을수록 고르다

확인 문제

12, 4, 6의 분산은?답 보기
평균 4, 편차 −2, 0, 2 → (4 + 0 + 4) ÷ 3 = 83
2네 변량의 편차가 −3, 1, x, 0이다. x는?답 보기
편차의 합 = 0 → −3 + 1 + x + 0 = 0 → x = 2
3두 반의 평균이 같고 표준편차가 A반 5, B반 2다. 성적이 더 고른 반은?답 보기
표준편차가 작은 B반
