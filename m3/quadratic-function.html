이차함수와 그 그래프

y = a(x − p)² + q, y = ax² + bx + c

한 줄로 외우기

이차함수의 그래프는 포물선이다. y = a(x − p)² + q 꼴로 바꾸면 꼭짓점 (p, q)가 바로 보인다.

왜 배울까?공을 던지면 날아가는 길, 분수의 물줄기가 포물선이다. 포물선의 꼭짓점은 가장 높은(또는 낮은) 곳이라서 '최대·최소'를 구하는 문제에 쓰인다.

  • y = ax² 의 그래프
  • y = a(x − p)² + q
  • y = ax² + bx + c

1y = ax² 의 그래프

  • 원점 (0, 0)이 꼭짓점이고, y축에 대해 좌우 대칭인 포물선
  • a > 0이면 아래로 볼록 (∪ 모양), a < 0이면 위로 볼록 (∩ 모양)
  • |a|가 클수록 폭이 좁아진다

2y = a(x − p)² + q

y = ax2의 그래프를 x축 방향으로 p만큼, y축 방향으로 q만큼 평행이동한 것이다.

  • 꼭짓점 (p, q)
  • 축의 방정식 x = p (그래프를 반으로 접는 선)
y = x²y = (x − 2)² + 1y = −½x²
주의
부호에 주의! y = (x − 2)2은 오른쪽으로 2, y = (x + 3)2 = (x − (−3))2은 왼쪽으로 3 이동한다.

3y = ax² + bx + c

완전제곱식을 만들어 y = a(x − p)2 + q 꼴로 바꾸면 꼭짓점을 찾을 수 있다.

y = x2 − 4x + 5
y = (x2 − 4x + 4) − 4 + 5 (x 계수의 절반을 제곱해서 더하고 뺌)
y = (x − 2)2 + 1 → 꼭짓점 (2, 1)
  • y절편은 c (x = 0을 넣은 값)
  • 꼭짓점의 x좌표 = −b2a
  • a > 0이면 꼭짓점에서 최솟값, a < 0이면 꼭짓점에서 최댓값

꼭 외울 것

  • 그래프 모양: 포물선
  • a > 0 아래로 볼록, a < 0 위로 볼록
  • |a|가 크면 폭이 좁다
  • y = a(x − p)² + q → 꼭짓점 (p, q), 축 x = p

확인 문제

1y = −2(x + 1)2 + 3 의 꼭짓점과 모양은?답 보기
꼭짓점 (−1, 3), a = −2 < 0 이므로 위로 볼록, 최댓값 3
2y = x2 + 6x + 8 의 꼭짓점은?답 보기
(x + 3)2 − 9 + 8 = (x + 3)2 − 1 → (−3, −1)
3y = 3x2 과 y = x2 중 폭이 더 좁은 것은?답 보기
|a|가 큰 y = 3x2
