일차방정식

문자와 식, 미지수

한 줄로 외우기

모르는 수를 x로 놓고 식을 세운 뒤, 등식의 양쪽을 똑같이 바꿔 x만 혼자 남긴다.

왜 배울까?초등학교의 '어떤 수 구하기'에서 □를 쓰던 자리에 이제 x를 쓴다. 문자를 쓰면 복잡한 문제도 식 하나로 정리되고, 정해진 순서대로 풀 수 있다.

1문자와 식

식을 쓸 때 곱셈 기호 ×를 생략한다. 숫자를 문자 앞에 쓰고, 1은 생략한다.

예
2 × x = 2x   /   1 × a = a   /   x × x = x2   /   a ÷ 3 = a3

2x + 3에서 2x, 3을 항, x 앞의 2를 계수, 숫자만 있는 3을 상수항이라 한다. 문자가 한 번만 곱해진 식(x1)을 일차식이라 한다.

문자가 같은 항(동류항)끼리는 더하고 뺄 수 있다: 2x + 3x = 5x, 7a − a = 6a

대입
x = 3일 때 2x + 1의 값 = 2 × 3 + 1 = 7 (이것을 '대입'이라고 한다)

2방정식과 해

등호(=)가 있는 식이 등식이다. x의 값에 따라 참이 되기도 하고 거짓이 되기도 하는 등식이 방정식, 참이 되게 하는 x의 값이 해(또는 근)다.

예
x + 3 = 10 → x = 7일 때만 참 → 해는 7
2x + x = 3x → x에 무엇을 넣어도 참 → 이런 식은 '항등식'

3등식의 성질 (저울)

등식은 균형 잡힌 저울과 같다. 양쪽에 똑같은 일을 하면 균형이 유지된다.

  • 양변에 같은 수를 더하거나 빼도 된다.
  • 양변에 같은 수를 곱해도 된다.
  • 양변을 0이 아닌 같은 수로 나누어도 된다.

4이항과 풀이

등식의 성질을 쓰면 한 항을 등호 반대쪽으로 옮길 수 있다. 이때 부호가 바뀐다. 이것을 이항이라 한다.

3x + 5 = 17
3x = 17 − 5 (+5를 이항하면 −5)
3x = 12
x = 4 (양변 ÷ 3)
예
괄호가 있으면 먼저 푼다: 2(x − 1) = x + 3 → 2x − 2 = x + 3 → 2x − x = 3 + 2 → x = 5

5활용 문제 푸는 순서

  1. 구하려는 것을 x로 놓는다.
  2. 문제의 문장을 식으로 옮긴다.
  3. 방정식을 푼다.
  4. 답이 문제에 맞는지 확인한다.
예
어떤 수의 3배에 4를 더하면 19다. → 3x + 4 = 19 → 3x = 15 → x = 5. 확인: 5×3+4 = 19 ✓

꼭 외울 것

  • 곱셈 기호 생략: 2 × x = 2x
  • 이항하면 부호가 바뀐다
  • 해를 구하면 원래 식에 넣어 확인한다

확인 문제

15x − 3 = 2x + 9답 보기
5x − 2x = 9 + 3 → 3x = 12 → x = 4
24(x + 1) = 2x − 6답 보기
4x + 4 = 2x − 6 → 2x = −10 → x = −5
3한 자루 300원인 연필을 몇 자루 사고 1000원을 냈더니 100원을 거슬러 받았다. 몇 자루일까?답 보기
1000 − 300x = 100 → 300x = 900 → x = 3자루
