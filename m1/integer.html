정수와 유리수

한 줄로 외우기

0보다 작은 수도 있다. 수직선에서 0의 오른쪽은 양수(+), 왼쪽은 음수(−)다.

왜 배울까?겨울 기온 '영하 5도', 엘리베이터 '지하 2층'처럼 0보다 작은 양을 나타내려면 새로운 수가 필요하다. 초등학교에서는 0보다 작은 수가 없었지만 중학교부터는 수가 0 아래로 넓어진다.

1양수와 음수

0보다 큰 수에는 +(양의 부호), 0보다 작은 수에는 −(음의 부호)를 붙인다. +3은 '양의 3', −3은 '음의 3'이라고 읽는다.

예
영상 5도 → +5  /  영하 5도 → −5
1000원 이익 → +1000  /  1000원 손해 → −1000

2정수와 유리수

정수: …, −3, −2, −1, 0, 1, 2, 3, …  (양의 정수 = 자연수, 0, 음의 정수)

유리수: 분수 꼴로 나타낼 수 있는 모든 수. −12, 0.3(=310), 5(=51)도 모두 유리수다. 그래서 정수는 유리수 안에 들어간다.

유리수
정수
자연수 1, 2, 3 …
0, −1, −2 …
12, −0.7 …

3수직선과 절댓값

수직선에서 0을 나타내는 점(원점)으로부터 어떤 수까지의 거리를 절댓값이라 하고 |a|로 쓴다. 거리라서 절댓값은 항상 0 이상이다.

예
|+3| = 3,   |−3| = 3,   |0| = 0

크기 비교: 수직선에서 오른쪽에 있을수록 크다. 음수끼리는 절댓값이 클수록 작다.

예
−5 < −2 < 0 < 3   (빚 5000원이 빚 2000원보다 더 나쁘다고 생각하면 쉽다)

4덧셈과 뺄셈

  • 부호가 같으면: 절댓값끼리 더하고 그 부호를 붙인다. (−2) + (−5) = −7
  • 부호가 다르면: 절댓값이 큰 쪽에서 작은 쪽을 빼고, 절댓값이 큰 쪽의 부호를 붙인다. (+3) + (−5) = −2
  • 뺄셈은 빼는 수의 부호를 바꾸어 더한다. (+2) − (−4) = (+2) + (+4) = 6
예
걸음으로 생각하기: +는 앞으로, −는 뒤로. 앞으로 3걸음, 뒤로 5걸음 가면 결국 뒤로 2걸음 → −2

5곱셈과 나눗셈

절댓값끼리 곱하거나 나누고, 부호는 이렇게 정한다.

부호결과예
(+) × (+)+3 × 4 = 12
(−) × (−)+(−3) × (−4) = 12
(+) × (−), (−) × (+)−3 × (−4) = −12

음수를 여러 개 곱하면 음수의 개수가 짝수면 +, 홀수면 −다. 나눗셈도 부호 규칙이 같다: (−12) ÷ 3 = −4

꼭 외울 것

  • 정수 ⊂ 유리수 (정수는 유리수에 포함)
  • 절댓값 = 0에서부터의 거리
  • 빼기 = 부호를 바꿔서 더하기
  • 같은 부호끼리 곱하면 +, 다르면 −

확인 문제

1(−7) + (+3) = ?답 보기
부호가 다르니 7 − 3 = 4, 절댓값이 큰 −7의 부호를 붙여 −4
2(+5) − (−2) = ?답 보기
부호를 바꿔 더한다: (+5) + (+2) = 7
3(−2) × (−3) × (−1) = ?답 보기
음수가 3개(홀수)라서 부호는 −, 2×3×1 = 6 → −6
